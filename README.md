# Networks-Simulation
Packet Tracer
Overview
The Network Simulation project was developed using Cisco Packet Tracer to simulate and configure a computer network. It focuses on understanding network communication, connectivity, and the configuration of essential networking concepts.
Technologies Used
Cisco Packet Tracer
Computer Networking
Key Concepts
IP Addressing and Subnetting
ARP (Address Resolution Protocol)
Routing and Switching
VLAN Configuration
Firewall Fundamentals
Project Objective
The main objective of this project is to gain practical experience in network design, configuration, and troubleshooting while understanding how different networking devices communicate within a network.
Technologies: Cisco Packet Tracer | Subnetting | ARP | Routing | Switching | VLAN | Firewall
